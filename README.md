# Netflix Data Analysis & Visualization (Python)

A data analysis project examining Netflix content distribution, country-wise content production, and release year trends using Python, Pandas, Matplotlib, and Seaborn.

---

## 📌 Project Overview

This project is part of the **Data Analysis Using Python Internship Program** at **Auspify Technologies**. It focuses on cleaning raw streaming data and uncovering key insights through exploratory data analysis (EDA).

### Tasks Completed:
1. **Task 1: Data Cleaning & Preparation**
   * Standardized column data types and whitespace across string fields.
   * Converted date attributes into structured datetime formats (`date_added`, `year_added`).
   * Cleaned raw records and exported `Cleaned_Dataset.csv`.

2. **Task 2: Content Type Distribution Analysis**
   * Categorized and counted the total proportion of Movies versus TV Shows available on Netflix.
   * Generated visual comparison charts (`Task2_Content_Type_Distribution.png`).

3. **Task 3: Country-Wise Content Production**
   * Extracted, split, and cleaned country metadata.
   * Identified and ranked the top 10 content-producing countries (`Task3_Top_10_Countries.png`).

4. **Task 4: Release Year Trend Analysis**
   * Aggregated title releases by release year (2000–2021).
   * Analyzed growth and distribution patterns over time (`Task4_Release_Year_Trends.png`).

---

## 🛠️ Tools & Libraries Used

* **Python 3.x**
* **Pandas** — Data manipulation & cleaning
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical plotting

---

## 📊 Key Findings & Insights

* **Movies vs. TV Shows:** Movies dominate the library, accounting for over **70%** of total content compared to TV Shows (~30%).
* **Top Country Contributor:** The **United States** leads production by a wide margin, followed by **India** and the **United Kingdom**.
* **Release Trends:** Content production experienced significant acceleration between **2015 and 2018**, reaching peak annual releases before stabilizing.
